# Security

Please report a vulnerability privately through **Security → Report a vulnerability** on this repository, not in a public issue.

Madoguchi gives AI agents read access to data, so its own security is the point of the project. The locks, what each one stops and how each one is tested are described in [docs/SECURITY_MODEL.md](docs/SECURITY_MODEL.md). `madoguchi check` tries every known way around them and fails if one works; CI runs it on every push.

Madoguchi never calls a language model by itself and holds no API key. The data it serves is fictional (generated by [Tsunagu](https://github.com/thibaultbordrie-cloud/tsunagu)).
